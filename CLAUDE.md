# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это за папка

Сайт-визитка ремонтной бригады. Название — «Честный ремонт», слоган — «Ремонтная бригада по доступным ценам» (так решил пользователь; в шапке название крупно, слоган под ним мелко; так же в `<title>`, Open Graph и JSON-LD). Карточка в Яндекс Бизнесе — «Честный Ремонт» (задание из `../Воркбук №1 — Лендинг для малого бизнеса.pdf`). Общие правила стека и вёрстки описаны в родительском `../CLAUDE.md` (он подгружается автоматически), здесь они не повторяются.

- Весь сайт — `index.html` в корне этой папки. JavaScript — только небольшой инлайн-скрипт в конце `<body>`: подсвечивает в меню текущий раздел (ставит `aria-current` по прокрутке). Без него всё работает, просто нет подсветки. Эта папка — git-репозиторий `remont-spb/remont-spb.github.io` (организация `remont-spb`, ветка `main`), сайт публикуется через GitHub Pages: https://remont-spb.github.io/
- Демо «Ракурс» из `../Сайт-визитка.zip` — только образец качества. Его тексты, палитру и приём «видоискатель» не переносить.

## Как посмотреть и опубликовать

```bash
start index.html
```

Сборки, линтеров и тестов нет. Проверять вёрстку на ширине телефона (320–375px, без горизонтальной прокрутки) и на десктопе.

Публикация — коммит и push в `main`, Pages пересобирает сайт сам (1–2 минуты). Git может не быть в `PATH` старых окон PowerShell — тогда вызывать `C:\Program Files\Git\cmd\git.exe`. Push из фоновой оболочки Claude не может спросить логин: если GitHub просит вход, запускать `git push` во вкладке Terminal, где пользователь сам входит в аккаунт.

## Поисковики

- В `<head>` — заголовок и описание для поиска, `canonical`, Open Graph и JSON-LD (`HomeAndConstructionBusiness`) с телефонами, регионом и часами работы. Меняются факты на странице — обновлять и JSON-LD.
- `robots.txt` и `sitemap.xml` в корне. При заметных правках страницы обновлять `<lastmod>` в `sitemap.xml`.
- Подтверждение прав в Яндекс Вебмастере — двумя способами: файл `yandex_8bc4201a25af74ee.html` и метатег `yandex-verification` в `<head>`. Не удалять и не менять, иначе права слетят. Такие файлы, скачанные пользователем, проверять: антивирус может вставить в них свой скрипт.
- `_config.yml` исключает `CLAUDE.md` из сборки Pages, иначе он публикуется как отдельная страница сайта. Новые служебные `.md` добавлять туда же.

## Структура страницы

Шапка (название + меню + кнопка «Связаться») → первый экран (`h1` + кнопки) → преимущества `#preimushchestva` → почему дешевле `#deshevle` → регионы `#regiony` → о компании `#o-nas` → цены `#ceny` → условия `#usloviya` → контакты и площадки `#kontakty` → подвал. Порядок и состав блоков задал пользователь; не менять без просьбы.

## Дизайн

- Палитра взята с товарного знака. Токены в `:root`: тёмно-синий `--navy #083762` (заголовки, тёмные секции), синий `--accent #146fb0` (кнопки, шаги, галочки; темнее голубого логотипа, чтобы белый текст читался), голубой `--sky #31b8e6` (акценты только на тёмно-синем фоне), фон секций `--mist #eef4fa`, текст `--ink #14263d`, `--muted #536176`, линии `--line #d9e4ef`. Новые цвета — только из этих токенов.
- Шрифты Google Fonts: заголовки — Unbounded, текст — Manrope.
- Единый стиль (просьба пользователя): все плашки, кнопки и иконки «переливаются» — заливки только градиентами из токенов `--grad-*` (синие кнопки и телефоны `--grad-blue`, круглые иконки с белым значком и номера шагов `--grad-icon`, тёмные блоки `--grad-navy`, светлые плашки `--grad-soft`, белые карточки `--grad-paper`, плашки на тёмном фоне `--grad-glass`). Плоских ярко-голубых заливок нет; `--sky` — только для мелких акцентов на тёмном фоне.
- Товарный знак: `img/logo-emblem-*.png` — эмблема (дом + щит) без надписей, с прозрачным фоном; `img/logo-full.jpg` — полный знак с надписью (для Open Graph и JSON-LD). Эмблема стоит в шапке, на первом экране, в подвале и как favicon. Исходник знака у пользователя; при замене логотипа пересобрать все размеры.
- Фирменный приём — сине-голубая линия `--brand-line` (под шапкой, над подвалом, низ блока цены) и ромбик у меток `.eyebrow`, как разделитель на товарном знаке. Не множить сверх этого.
- Тёмно-синие секции (`.section-dark`) чередуются со светлыми; на тёмном фоне акцент — `--sky`, на светлом — `--accent`.
- Первый экран (`.hero`) тёмно-синий: главная кнопка — синий градиент с белым текстом, эмблема на белом круге (её тёмно-синий контур иначе сливается с фоном), под ней девиз с товарного знака «Прозрачность. Доверие. Технологии.».
- Плашки (так попросил пользователь): «Почему дешевле» (заголовок «…а не за офис и менеджеров») — полупрозрачные голубые на тёмном фоне, со значками в сине-голубых кругах вместо номеров; «О компании» — яркие плашки с цифрами (сине-голубой градиент, белый текст), «Кому мы подходим» — тёмно-синяя; «Без предоплаты» — светло-голубая `.card-accent`, остальные карточки условий и цен — белые; регионы и пояснение про замер — тёмно-синие.
- «Преимущества» — без сетки плашек (пользователю не понравилась): слева тёмно-синий акцент `.adv-feature` «3 года гарантии», справа список `.adv-list` с круглыми сине-голубыми иконками и тонкими разделителями.
- Контакты: короткий заголовок «Запишитесь бесплатно», под ним два предложения списком с иконками (замер бесплатно, смета по дизайн-проекту в подарок), телефоны — крупные переливающиеся кнопки звонка `.phone-card` (на узком телефоне номер в одну строку). Плашки в блоке — только у телефонов (пользователь просил не перегружать), «Где нас найти» — список с тонкими разделителями.
- Номера шагов 1–6 — тот же перелив `--grad-icon`, что у иконок.
- «Как мы работаем»: шаги 1–6 без общей плашки, между ними сплошная линия со стрелкой (на телефоне — вниз), не пунктир.
- Кнопки «Рассчитать смету по дизайн-проекту в подарок» (с иконкой подарка) — на первом экране вместо «Узнать цены» и вторая кнопка в блоке цены. Факт из базы знаний: смета по дизайн-проекту бесплатна.
- В шапке пункты меню — светло-голубые плашки с рамкой, текущий раздел — с синей рамкой. Кнопка «Связаться» крупнее, с иконкой телефона и тенью, чтобы выделяться на их фоне. На ширине 861–1080px кнопка скрыта: её заменяет пункт «Контакты». На телефоне меню скрыто, кнопка видна.

## Откуда брать факты о бизнесе

Источник — база знаний бригады, файлы лежат рядом с `index.html`:

- `База Знаний Ремонтная бригада.docx` — преимущества, почему дешевле, регионы, о компании, цены, условия, контакты (главный источник).
- `FAQ  Ремонтная бригада.txt` — уточнения: что входит в цену, мусор, график, оплата, объекты с проживанием.
- `Tone-of-Voice Ремонтная бригада.txt` — на «Вы» (с заглавной), тепло, коротко, без пафоса и стоп-слов из этого файла.

На сайте только факты из этих файлов. Чего там нет — не придумывать, а спросить. Если файлы обновились — сверить с ними `index.html`.

Решения пользователя, которые отличаются от формулировок базы знаний: цена на сайте — «от 15 000 ₽ за м²» (в базе «в среднем 15 000–18 000»); так же в meta description, Open Graph и JSON-LD.

Word и Python здесь не установлены. Текст из docx читать так (файл часто открыт в редакторе, поэтому `ReadWrite`):

```powershell
Add-Type -AssemblyName System.IO.Compression; $fs = [IO.File]::Open((Resolve-Path 'База Знаний Ремонтная бригада.docx').Path, 'Open', 'Read', 'ReadWrite'); $z = New-Object IO.Compression.ZipArchive($fs, 'Read'); $r = New-Object IO.StreamReader($z.GetEntry('word/document.xml').Open(), [Text.Encoding]::UTF8); $x = $r.ReadToEnd(); $r.Close(); $z.Dispose(); $fs.Close(); [Net.WebUtility]::HtmlDecode(($x -replace '</w:p>', "`n" -replace '<[^>]+>', '')) -split "`n" | Where-Object { $_.Trim() }
```

Пока нет в источниках и потому нет на сайте: почта (в docx поле пустое), ссылки на площадки (Авито, соцсети и т. п.), отзывы.

Файлы базы знаний — не часть сайта: они в `.gitignore` и в публичный репозиторий не попадают. Выкладывать их только по прямой просьбе пользователя. Фото и видео работ есть у пользователя в папке «Фото ремонты» (в основном видео .MOV/.mp4 и .HEIC, их нужно конвертировать для веба). Подпапки названы по клиентам — имена клиентов на сайт не выносить.
