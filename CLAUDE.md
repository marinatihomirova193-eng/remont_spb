# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это за папка

Сайт-визитка ремонтной бригады «Ремонтная бригада по доступным ценам» (задание из `../Воркбук №1 — Лендинг для малого бизнеса.pdf`). Общие правила стека и вёрстки описаны в родительском `../CLAUDE.md` (он подгружается автоматически), здесь они не повторяются.

- Весь сайт — `index.html` в корне этой папки. JavaScript — только небольшой инлайн-скрипт в конце `<body>`: подсвечивает в меню текущий раздел (ставит `aria-current` по прокрутке). Без него всё работает, просто нет подсветки. Эта папка — git-репозиторий `marinatihomirova193-eng/remont_spb` (ветка `main`), сайт публикуется через GitHub Pages: https://marinatihomirova193-eng.github.io/remont_spb/
- Демо «Ракурс» из `../Сайт-визитка.zip` — только образец качества. Его тексты, палитру и приём «видоискатель» не переносить.

## Как посмотреть и опубликовать

```bash
start index.html
```

Сборки, линтеров и тестов нет. Проверять вёрстку на ширине телефона (320–375px, без горизонтальной прокрутки) и на десктопе.

Публикация — коммит и push в `main`, Pages пересобирает сайт сам (1–2 минуты). Git может не быть в `PATH` старых окон PowerShell — тогда вызывать `C:\Program Files\Git\cmd\git.exe`. Push из фоновой оболочки Claude не может спросить логин: если GitHub просит вход, запускать `git push` во вкладке Terminal, где пользователь сам входит в аккаунт.

## Структура страницы

Шапка (название + меню + кнопка «Связаться») → первый экран (`h1` + кнопки) → преимущества `#preimushchestva` → почему дешевле `#deshevle` → регионы `#regiony` → о компании `#o-nas` → цены `#ceny` → условия `#usloviya` → контакты и площадки `#kontakty` → подвал. Порядок и состав блоков задал пользователь; не менять без просьбы.

## Дизайн

- Токены в `:root`: графит `--ink #1c1d1f`, белый `--paper`, фон секций «бетон» `--concrete #f3f1ec`, акцент строительный жёлтый `--accent #f5b800` (тёмный `#d9a300`), серый текст `--muted #5e6168`, линии `--line #e4e1da`.
- Шрифты Google Fonts: заголовки — Unbounded, текст — Manrope.
- Фирменный приём — сигнальная лента (жёлто-чёрная диагональная полоса, `--stripe`): под шапкой, над подвалом, в метках `.eyebrow` и на иллюстрации героя. Не множить сверх этого.
- Тёмные секции (`.section-dark`) чередуются со светлыми; текст на жёлтом — всегда тёмный.
- В шапке жёлтая плашка означает «Вы здесь» (текущий раздел), поэтому кнопка «Связаться» в шапке тёмная. На ширине 861–1080px кнопка скрыта: её заменяет пункт «Контакты». На телефоне меню скрыто, кнопка видна.

## Откуда брать факты о бизнесе

Источник — база знаний бригады, файлы лежат рядом с `index.html`:

- `База Знаний Ремонтная бригада.docx` — преимущества, почему дешевле, регионы, о компании, цены, условия, контакты (главный источник).
- `FAQ  Ремонтная бригада.txt` — уточнения: что входит в цену, мусор, график, оплата, объекты с проживанием.
- `Tone-of-Voice Ремонтная бригада.txt` — на «Вы» (с заглавной), тепло, коротко, без пафоса и стоп-слов из этого файла.

На сайте только факты из этих файлов. Чего там нет — не придумывать, а спросить. Если файлы обновились — сверить с ними `index.html`.

Word и Python здесь не установлены. Текст из docx читать так (файл часто открыт в редакторе, поэтому `ReadWrite`):

```powershell
Add-Type -AssemblyName System.IO.Compression; $fs = [IO.File]::Open((Resolve-Path 'База Знаний Ремонтная бригада.docx').Path, 'Open', 'Read', 'ReadWrite'); $z = New-Object IO.Compression.ZipArchive($fs, 'Read'); $r = New-Object IO.StreamReader($z.GetEntry('word/document.xml').Open(), [Text.Encoding]::UTF8); $x = $r.ReadToEnd(); $r.Close(); $z.Dispose(); $fs.Close(); [Net.WebUtility]::HtmlDecode(($x -replace '</w:p>', "`n" -replace '<[^>]+>', '')) -split "`n" | Where-Object { $_.Trim() }
```

Пока нет в источниках и потому нет на сайте: почта (в docx поле пустое), ссылки на площадки (Авито, соцсети и т. п.), отзывы.

Файлы базы знаний — не часть сайта: они в `.gitignore` и в публичный репозиторий не попадают. Выкладывать их только по прямой просьбе пользователя. Фото и видео работ есть у пользователя в папке «Фото ремонты» (в основном видео .MOV/.mp4 и .HEIC, их нужно конвертировать для веба). Подпапки названы по клиентам — имена клиентов на сайт не выносить.
